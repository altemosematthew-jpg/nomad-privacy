Mapelago

About Mapelago

Mapelago is a free daily geography game made in Nashville, Tennessee. One mystery city a day, the same for everyone.

The idea

Most map games hand you clues. Here you earn them. Sliding and merging tiles costs points and buys information, so every game is a small decision: one more clue, or pin now.

The name is map plus archipelago. The look comes from sea charts: white for deep water, blue for the shallows, buff for land, and magenta for anything a navigator needs to notice.

How it was made

One person designed and directed the game. The code was written with AI coding tools (Claude, by Anthropic), then tested by playing full games in a browser.

No image generator was used. The turtle, the icons and the maps are vector drawings written as code.

The cities and clues are generated from open data, so a clue can occasionally be wrong.
